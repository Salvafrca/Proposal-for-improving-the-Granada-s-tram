# Proposal-for-improving-the-Granada-s-tram
As a project for the fourth-year course 'Projects' in the Physics degree at the University of Granada, we were tasked with proposing an improvement to a public element or service in the city of Granada. 

My team and I decided to create an interactive application to facilitate interaction between the tram and its users.

This application, designed in Spanish, is an interactive working model built using hyperlinks that allow the user to interact with the document in a way analogous to a real app.

The design and all drop-down menus are intended to improve transportation services by implementing features such:
- Advertising campaigns
- Parental control
- Real-time tracking
- Automated balance-reloading model
